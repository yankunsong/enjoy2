# Local Web Enjoy 复用整个渲染层，不做裁剪

Local Web Enjoy 只需要 Shadowing 与 Assessment 两条链路，但它复用 Desktop Enjoy 的**全部**渲染层源码，包括 chat、community、course 等用不上的页面。这些页面照常被编译进产物，只是不在侧边栏提供入口。

理由是这个项目真正值钱的部分恰好集中在 Shadowing 界面：波形、区间循环、音高曲线、录音与原声双轨对比、逐句状态机。重写它们是数周的工作量，且产物大概率不如现有的。而删除用不上的页面会因为组件互相引用而制造编译错误，收益为零。

## Consequences

产物里存在大量永远不会被访问的代码。**不要"清理"它们**——那不是遗留物，是刻意保留的。同理，直接输入地址仍可进入这些页面，届时看到报错属于预期行为，不是 bug。
